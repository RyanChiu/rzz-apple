# Security Policy

## Supported Versions

This project is currently maintained on the `main` branch.

## Reporting a Vulnerability

Please do **not** open a public issue for security-sensitive reports.

- Preferred: email `ryan.chiu@hotmail.com` with subject `RZZ Security Report`
- Alternate: create a GitHub issue only for non-sensitive security hardening suggestions

When reporting, include:

- Affected version/commit
- Reproduction steps
- Expected impact
- Any proof-of-concept details

## Response Process

- Initial triage target: within 5 business days
- If confirmed, a fix will be prepared and released as soon as practical
- Public disclosure is recommended after a fix is available
